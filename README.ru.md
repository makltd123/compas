# Compas — семантический поиск по российским компаниям

[English](README.md) | **Русский**

B2B-поисковик, который находит российские компании по смыслу запроса, а не по ключевым словам. Пишете так, как спросили бы коллегу, — «производители металлоконструкций в Екатеринбурге» или «IT-аутсорсинг для банков, Казань» — и получаете подходящие компании с контактами, описанием и финансовыми данными.

Сделан в 2026 году как стартап. Код продукта и данные закрыты; этот репозиторий рассказывает, как он устроен и насколько хорошо работает.

## Что умеет

- Поиск на естественном языке по ~147 000 компаний; город определяется из запроса или задаётся явно.
- Карточка компании: чем занимается, продукты, клиенты, география, контакты, а примерно у половины компаний — финансовые показатели.
- «Похожие компании» для любого результата.
- Сохранённые списки, история поиска и выгрузка в Excel.
- По описанию вашего продукта: портрет идеального клиента (ICP) и холодное письмо.
- Вход по ссылке из письма, бесплатный и платный тарифы с лимитами.

## Как это работает

```
справочники компаний, сканирование доменной зоны
        │
        ▼
проверка миллионов URL на доступность (200 параллельных потоков)
        │
        ▼
краулинг сайтов: обычный HTTP, контакты из HTML, старые страницы в Windows-1251
        │
        ▼
извлечение через LLM (Mistral): текст сайта → структурированный профиль компании (JSON)
        │
        ▼
эмбеддинги дообученной моделью BGE-M3 (1024 измерения) → векторная база (Zilliz)
        │
        ▼
финансовое обогащение: координаты компании → ближайшая запись ФНС → ИНН → реестр МСП → численность
```

Поисковый запрос переводится в вектор той же моделью, город берётся из запроса или фильтра, и из векторного индекса возвращаются ближайшие компании с подтянутыми финансовыми данными.

Модель эмбеддингов дообучена на данных компаний под русскоязычные B2B-запросы и опубликована: [`makltd1/compas-bge-m3-ru`](https://huggingface.co/makltd1/compas-bge-m3-ru).

## Качество поиска

Поиск оценивался автоматически, а не на глаз. Результаты последней оценки (июнь 2026):

**Покрытие.** 1000 запросов = 40 отраслей × 25 городов, оценка по сходству лучших совпадений:

| Результат | Запросов |
|---|---|
| хорошо (≥ 40%) | 691 |
| средне (30–39%) | 155 |
| пробел (< 30%) | 154 |

**Релевантность.** LLM-судья оценил топ-30 результатов каждого запроса по шкале от 1 до 10 — всего 63 600 пар «запрос — компания»:

- 14 718 пар (23%) релевантны (≥ 7), 22 151 (35%) — нет (≤ 3);
- среди результатов, в которых поиск был уверен (сходство ≥ 56%), 20,7% всё равно оказались нерелевантными;
- оценка судьи растёт вместе со score поиска — от 4,0 в среднем ниже 50% до 6,1 выше 60%, — то есть score осмысленный.

**Устойчивость** — как меняется выдача, если то же намерение сформулировать иначе:

| Стиль запроса | Изменение score | Совпадение топ-5 со стандартной формулировкой |
|---|---|---|
| с опечатками | −1,2% | 73% |
| в форме вопроса | −2,3% | 67% |
| в форме требований | −3,3% | 62% |
| развёрнутый | −4,7% | 55% |
| на английском | −5,6% | 7% |
| короткий | −6,0% | 16% |

**Что из этого следует.** Главное ограничение — покрытие, а не модель: некоторые отрасли (производство продуктов питания, медицинские клиники, кадровые агентства) слабо представлены в данных, и поиск не может найти то, чего там нет. Сильнее всего выдачу меняют короткие запросы и запросы на английском.
